CGLib (Camera Geometry Library) is a modern Python package that simplifies camera calibration and geometric corrections for industrial and AI-driven computer vision systems.
It enables engineers to quickly compute camera intrinsics, export them as reusable parameters, and apply distortion correction in production pipelines.

Designed for robustness and clarity, CGLib focuses on practical use cases such as robotics, quality inspection, mining/mineral vision, and deep learning vision tasks.
